🛍️ NovaCart

NovaCart is a modern premium e-commerce web application built using React.js and Tailwind CSS. The platform provides a responsive shopping experience with dynamic product listing, category filtering, shopping cart management, authentication UI, and a clean fashion-inspired user interface.

The project focuses on frontend architecture, reusable React components, state management using Context API, API integration, and responsive design principles commonly used in modern e-commerce applications. React and Tailwind CSS are widely used technologies for modern e-commerce frontends and storefront experiences.

⚙️ Installation

Clone the repository:

git clone https://github.com/dhruvrathod45/NovaCart-ecommerce-web.git

Move into the project:

cd NovaCart-ecommerce-web

Install dependencies:

npm install

Start development server:

npm run dev

Build production version:

npm run build

Preview production build:

npm run preview
